# Workout Export

Eine iPhone-App von **Werkbank Apps**, die ausgewählte Workouts aus Apple Health als kompakte JSON- oder CSV-Datei exportiert – ideal zur Analyse mit einer KI oder in einer Tabelle, ohne den kompletten Health-Export.

## Datenschutz

- Die App **liest** Workouts und Messwerte aus Apple Health, schreibt aber nichts.
- Es gibt **keine Server, keine Analyse- und keine Werbedienste**. Der Code enthält keinerlei Netzwerkzugriffe.
- Daten verlassen das iPhone nur, wenn du eine Export-Datei selbst teilst.

Der Quellcode ist Open Source, damit du das selbst nachprüfen kannst.

## Funktionen

- Letzte Workouts laden, nach Sportart filtern und gezielt auswählen
- Export als JSON (inkl. Herzfrequenz pro Minute) oder CSV
- Sportart, Dauer, Distanz, Herzfrequenz, Energie, Höhenmeter, Lauf- und Radwerte, Anstrengung, Ruhepuls und VO2max

## Technik

SwiftUI und HealthKit, iOS 26 oder neuer, nur iPhone.
